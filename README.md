# 🏡 AIArchitect — Visualize Before You Build

**AI-powered architectural visualization for smarter building design.**

AIArchitect is a web-based architectural visualization prototype designed to help users explore building concepts before construction. It combines interactive 3D visualization with an architecture-focused design experience, with the goal of making early-stage planning more accessible and intuitive.

## ✨ Features

- **Interactive 3D Preview:** Explore a generated house model in a 3D environment.
- **Customizable Design Inputs:** Configure plot dimensions, number of floors, architectural style, and budget.
- **3D Model Export:** Export the generated house model as a GLB file.
- **AI-Assisted Design Vision:** A planned workflow for refining architectural concepts through natural-language prompts.
- **AR Visualization Vision:** Designed with the goal of viewing proposed building models in real-world surroundings using compatible mobile devices.

## 🎯 Problem Statement

Visualizing a building before construction can be difficult without architectural expertise, specialized software, or expensive design services. Changes made late in the planning process can also increase complexity and cost.

AIArchitect aims to make early architectural visualization more approachable by bringing customizable 3D building concepts into a browser-based experience.

## 💡 Our Solution

AIArchitect provides an interactive environment where users can explore a house concept, adjust design parameters, inspect its 3D representation, and export the model for further use.

Our long-term vision is to combine AI-assisted architectural redesign with immersive AR visualization, helping users better understand their ideas before construction begins.

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **3D Graphics:** Three.js
- **3D Model Export:** GLTFExporter / GLB
- **Development Server & Build Tool:** Vite
- **Version Control:** Git and GitHub
- **Deployment:** Vercel (planned or in progress)
